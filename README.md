# Superstore Sales Data Visualization

## Project Overview

This project focuses on transforming raw sales data into meaningful visual insights using Python and Matplotlib. Various visualizations were created to analyze sales performance, profitability, customer segments, regional trends, and product performance.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Dataset

The Superstore dataset contains information about:

* Orders
* Customers
* Products
* Sales
* Profit
* Regions
* Customer Segments

## Visualizations Included

### Sales Analysis

* Sales by Category
* Sales by Region
* Monthly Sales Trend

### Profit Analysis

* Profit by Category
* Profit Distribution
* Sales vs Profit Scatter Plot

### Customer Analysis

* Customer Segment Distribution

### Product Analysis

* Top 10 Products by Sales

## Key Findings

1. Technology category generated the highest sales.
2. Profitability varies significantly among categories.
3. Regional sales performance differs across markets.
4. Consumer segment contributes the largest customer share.
5. Monthly sales show noticeable fluctuations over time.
6. Higher sales do not always guarantee higher profit.
7. A small group of products contributes a large portion of total sales.

## Conclusion

This project demonstrates how data visualization can help identify trends, patterns, and business opportunities. By converting raw data into visual insights, organizations can make more informed and data-driven decisions.
